# Saved output status

`combined_predictions.xlsx` is a legacy workbook copied from the `dev_yg` branch. It contains earlier annotation predictions and consensus counts; it does not represent the final annotation results reported in the manuscript. The final updated workbook was not found in the uploaded folders or branch archives, so this file is retained for provenance and should not be cited or presented as the manuscript result.

`approach3_deepshap_marker_table.json` and `all_approaches_umap.png` are saved artifacts from the selected marker/annotation workflow. The marker checkpoints and source AnnData objects needed to regenerate them are not included.
